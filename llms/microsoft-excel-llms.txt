# Microsoft Excel

> APIs for automating, integrating, and extending Microsoft Excel — workbook management, data manipulation, charting, and formula execution — primarily through the Microsoft Graph REST API, plus the Excel JavaScript (Office Add-ins) and Office Scripts automation surfaces.

## APIs

- [Microsoft Graph Excel API](https://learn.microsoft.com/en-us/graph/api/resources/excel): REST API for worksheets, tables, rows, columns, charts, ranges, named items, sessions, and workbook functions on files in OneDrive/SharePoint. Base URL https://graph.microsoft.com/v1.0
- [Excel JavaScript API](https://learn.microsoft.com/en-us/javascript/api/excel): Office Add-ins client-side API (JavaScript/TypeScript)
- [Office Scripts API](https://learn.microsoft.com/en-us/office/dev/scripts/overview/excel): TypeScript automation for Excel on the web with Power Automate integration
