APIs for automating, integrating, and extending Microsoft Excel functionality including workbook management, data manipulation, charting, and formula execution through Microsoft Graph REST APIs.

**Areas:** Automation · Data Analysis · Microsoft · Microsoft 365 · Office · Spreadsheets

## Microsoft Excel on APIs.io

Everything profiled for Microsoft Excel is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/microsoft-excel/](https://apis.io/providers/microsoft-excel/)** — or go straight to one of the APIs or properties below.

### APIs (11)

- [Excel JavaScript API](https://apis.io/apis/microsoft-excel/excel-javascript-api/) — Office Add-ins API for building custom functionality within Excel using JavaScript and TypeScript.
- [Office Scripts API](https://apis.io/apis/microsoft-excel/office-scripts-api/) — TypeScript-based automation for Excel on the web, enabling Power Automate integration for business process automation.
- [Microsoft Excel Charts API](https://apis.io/apis/microsoft-excel/microsoft-excel-charts-api/) — Operations for managing charts within worksheets.
- [Microsoft Excel Functions API](https://apis.io/apis/microsoft-excel/microsoft-excel-functions-api/) — Workbook function operations.
- [Microsoft Excel Named Items API](https://apis.io/apis/microsoft-excel/microsoft-excel-named-items-api/) — Operations for managing named ranges and values.
- [Microsoft Excel Ranges API](https://apis.io/apis/microsoft-excel/microsoft-excel-ranges-api/) — Operations for reading and writing cell ranges.
- [Microsoft Excel Sessions API](https://apis.io/apis/microsoft-excel/microsoft-excel-sessions-api/) — Workbook session management operations.
- [Microsoft Excel Table Columns API](https://apis.io/apis/microsoft-excel/microsoft-excel-table-columns-api/) — Operations for managing table columns.
- [Microsoft Excel Table Rows API](https://apis.io/apis/microsoft-excel/microsoft-excel-table-rows-api/) — Operations for managing table row data.
- [Microsoft Excel Tables API](https://apis.io/apis/microsoft-excel/microsoft-excel-tables-api/) — Operations for managing tables within worksheets.
- [Microsoft Excel Worksheets API](https://apis.io/apis/microsoft-excel/microsoft-excel-worksheets-api/) — Operations for managing worksheets within a workbook.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Microsoft Excel: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
